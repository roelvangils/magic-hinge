# Magic Hinge 0.9.1 Beta

A new folded-glass app icon with native light and dark appearances, a matching
website icon and a refreshed blue, cyan and lilac palette. The app also retains
a classic icon for older supported macOS versions.

This update preserves the bundle identifier, preferences and downloaded models.
It includes the existing Swift compiler compatibility fixes. The website now
loads without the initial laptop position jump and uses a lighter 0–3° idle
animation, with accessible appearance and motion controls.

This remains a public beta for Apple silicon, macOS 14.2 or later. Runtime testing
on macOS 14.2, the full physical hinge/sleep/clamshell matrix, the complete
permission-state matrix and VoiceOver acceptance remain outstanding. Sensor
availability is detected at runtime; the simulator works without a sensor.

Validation: signed Developer ID app; native Aqua/DarkAqua icon stacks and classic
ICNS verified; website theme switching and contrast checked. The app and DMG passed Apple notarization, stapling and Gatekeeper validation.
